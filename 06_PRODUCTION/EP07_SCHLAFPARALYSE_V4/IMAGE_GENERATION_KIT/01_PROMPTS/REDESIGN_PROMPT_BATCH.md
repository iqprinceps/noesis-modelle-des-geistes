# EP07 — Diversity Redesign Prompt Batch

Reproduzierbare Nachbesserungsbatch für die zwölf ausgetauschten Motive. Die kanonischen Einzelprompts stehen in den vier `NANOBANANA_PROMPTS_V4_*.md`-Dateien; diese Batch dokumentiert Dateiname, Referenzen und Motivkern in einer ausführbaren Reihenfolge.

## Globale Vorgaben

- Ausgabe: 2K, horizontal 16:9, PNG.
- Stil: tief, mystisch, intellektuell komplex, dokumentarisch vorsichtig; Graphit, Leinen, gealtertes Papier, ruhiges Indigo, warme neutrale Lichtanker und subtile Körnung.
- Lesbarkeit: angehobene Mitteltöne, sichtbare Schattendetails, klare Blickführung auf Handy- und Laptopbildschirm; große Flächen nicht in Schwarz absaufen lassen.
- Diversity-Lock: kein Bett, kein Schlafzimmer, keine schlafende oder liegende Person in diesen zwölf Ersatzmotiven.
- Kein generischer Horrorgeist, keine leuchtenden Augen, keine Fantasy-Magie, kein Dämonenklischee, keine erfundene Genealogie.
- Kein generierter lesbarer Text, keine Fantasieschrift, Labels, Logos oder Wasserzeichen.
- Historische Referenzen bleiben separate, unveränderte Quellenobjekte. Nicht nachzeichnen, umschreiben, animieren oder zu erfundener Geschichte verschmelzen.
- Leere Flächen sind für spätere Editor-Typografie vorgesehen.

## Vertex-Ausführung

Das reproduzierbare Skript liegt unter `tools/ep07_diversity_redesign.py`. Es erzeugt die zwölf 2K-Fassungen einzeln über `gemini-3-pro-image`; `tools/ep07_diversity_composite.py` setzt danach die Originalscans quelltreu ein.

```powershell
python tools\ep07_diversity_redesign.py --overwrite
python tools\ep07_diversity_composite.py
```

Einzelne Nachbesserung:

```powershell
python tools\ep07_diversity_redesign.py --only IMG017_FEAR_SLEEP_FEEDBACK_LOOP_BASE.png --overwrite
python tools\ep07_diversity_composite.py
```
