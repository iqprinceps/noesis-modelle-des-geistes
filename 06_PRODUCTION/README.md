# Deutsche Produktionsstände

Dieser Ordner enthält die deutschen Produktionspakete, Timelines, QA-Berichte
und Pipeline-Dateien. Große Medien werden durch `.gitignore` lokal gehalten.

## Aktuell maßgebliche Produktionsfamilien

| Thema | Maßgeblicher Produktionsordner |
|---|---|
| Kozyrev / Spiegel | `EP01A_SPIEGEL/` beziehungsweise veröffentlichter Kozyrev-Stand |
| Gateway | `EP02_GATEWAY_V7/` |
| PEAR | `EP03_PEAR/` mit dem gekennzeichneten V2-Finalstand |
| Jung / Kundalini | `JUNG_SERIES_V1/` |
| Schlafparalyse I–III | `EP06_SCHLAFPARALYSE_V4/`, `EP07_SCHLAFPARALYSE_V4/`, `EP08_SCHLAFPARALYSE_V4/` |
| Deutsche Schlafparalyse-Shorts | `SCHLAFPARALYSE_SHORTS_V1/` |

Ordner wie `EP02_GATEWAY_V2` bis `V6`, `Gateway_Production` oder ältere
Kozyrev-Varianten bleiben vorerst als Pipeline- und Vergleichshistorie erhalten.
Sie sind keine Vorlage für neue Drehbücher und werden nicht mehr als aktueller
Kanon bezeichnet.

Produktionskritische Verzeichnisse werden nicht willkürlich verschoben. Ein
späterer Archivumzug erfolgt nur zusammen mit aktualisierten Toolpfaden und
einem erfolgreichen Pfad-/Render-Preflight.
