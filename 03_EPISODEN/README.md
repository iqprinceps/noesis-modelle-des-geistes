# Episodenentwicklung

Hier entstehen deutsche Themen-, Recherche- und Drehbuchpakete. Die Typen A, B
und C sind dramaturgische Orientierung, keine starren Formate.

- `TYPE_A/` — Akte, Maschine, Experiment oder institutioneller Widerspruch
- `TYPE_B/` — Bewusstsein, Symbol, innere Erfahrung oder kulturelle Landkarte
- `TYPE_C/` — offenes wissenschaftliches Rätsel oder Kontroverse

Neue Themen erhalten einen eigenen eindeutig benannten Episodenordner. Die
Arbeit beginnt mit dem Briefing in
[`../02_GUIDES/CHATGPT_DREHBUCH_BRIEF.md`](../02_GUIDES/CHATGPT_DREHBUCH_BRIEF.md).
Ein fertig produzierter deutscher Stand wandert in `06_PRODUCTION`; eine
englische Adaption in `07_ENGLISH_PRODUCTION`.

Vorhandene Episoden sind Lernmaterial. Ihre Form, Länge und Assetmenge werden
nicht automatisch auf ein neues Thema übertragen.
