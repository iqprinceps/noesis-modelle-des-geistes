# EP01 Companion Shorts – Produktionsstandard

- Format: 1080 × 1920, 9:16, 30 fps
- Ziellänge: 35–55 Sekunden, niemals über 59 Sekunden
- Sprache: Deutsch; Jahreszahlen und schwierige Begriffe TTS-sicher formuliert
- Voice: ElevenLabs `TUKJhQmz3RPYBNAgC5A1`, kapitelweise pro Short
- Bildwechsel: im Mittel alle 2–4 Sekunden; kein identischer Shot direkt wiederholt
- Safe Area: Kernaussage und Gesichter zwischen y=260 und y=1500
- Untertitel: eingebrannt, maximal zwei Zeilen; keine UI-relevanten Elemente am rechten Rand
- Bildästhetik: investigative Dokumentation, kaltes Blaugrün, warmes Metalllicht, dezentes Filmkorn
- Maschinenkontinuität: dieselbe offene, begehbare Aluminiumspirale wie in EP01; eine Person sitzt oder steht im Inneren, niemals davor
- Generierte Bilder enthalten keine eingebettete Schrift. Typografie wird im Schnitt korrekt gesetzt.
