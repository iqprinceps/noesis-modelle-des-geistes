# EP01B V3 — Visual Dramaturgie

**Source of Truth:** `DREHBUCH.md` + `ASSET_PLAN_V3.md` + `asset_manifest_v3.csv`

## Ziel

Bild und Sprechertext sollen nicht nur gleichzeitig laufen, sondern dieselbe Informationsebene tragen. Jeder visuelle Wechsel braucht eine Funktion: **Beweis, Orientierung, Verstehen, Spannung oder Nachhall.**

---

## S1 — Der Streifen auf dem Mond

### Voice-Funktion
Dokumentierter Hook: Datum, Ort, Krater, unerwartetes Signal, Kontroverse, Kozyrev als realer Astronom.

### Bildfolge
1. **0:00–0:04 — A02 Alphonsus LRO**: langsamer Push auf Zentralbereich.
2. **0:04–0:10 — C01 Rekonstruktion Observatorium**: Kozyrev am Instrument; keine Spiegel.
3. **0:10–0:17 — C02 Spektralplatte**: analog, sachlich, ein einzelnes ungewoehnliches Signal.
4. **0:17–0:25 — A03 Apollo-Alphonsus**: anderer realer Blick auf denselben Krater.
5. **0:25–0:34 — D01 `3 NOVEMBER 1958 / ALPHONSUS`**.
6. **0:34–0:45 — A01 Kozyrev-Portraet**: Identitaetsreveal.
7. **0:45–Ende S1 — kurzer Concept Bridge**: Zeit als Frage, nicht als Effekt; Spiegel nur als sehr spaete Text-Andeutung, visuell noch nicht zeigen.

### Rhythmus
Hook schnell, danach einen laengeren Hold auf Kozyrev zulassen. Der Zuschauer soll die Person abspeichern.

## S8 — Was von Kozyrev bleibt

### Voice-Funktion
Synthesis: reale Person, echte Fragen, unbestaetigte Theorie, kulturelles Nachleben.

### Bildfolge
1. **A02 Alphonsus** — Rueckkehr zum Anfang.
2. **A01 Kozyrev** — langer ruhiger Push.
3. **C17 Reise-Montage**: Observatorium -> Haft -> Mond -> Theorie -> spaetere Spiegel.
4. **A11/A13** nur kurz als spaete Nachwirkung.
5. **C18 Schlussbild**: Observatorium/Mond/ferne Aluminiumform.
6. Auf Endline keine neue Information mehr einfuehren.

### Letzter visueller Lock
Bei `Kozyrev hat keine Zeitmaschine gebaut.` Bild reduziert und sachlich.  
Bei `Die Nachwelt hat aus Kozyrev eine gebaut.` erst dann die spaete Aluminiumspirale in die Komposition treten lassen.

# Synchronisationsregeln

- **Originalasset immer auf einen faktischen Satz legen.**
- **AI-Rekonstruktion nie exakt auf einen Satz legen, der fotografische Dokumentation suggeriert.**
- Bei `berichtet`, `glaubt`, `behauptet`, `seiner Ansicht nach` visuell keine bestaetigende Wunderwirkung zeigen.
- Bei Replikationskritik keine laecherlich wirkende Apparatur verwenden; serioese Laboraesthetik beibehalten.
- Patent-Reveal mindestens 10–15 Sekunden visuell klar halten; das ist kein beilaufiger Insert.
- Spiegel vor S7 vermeiden, damit der zweite Reveal funktioniert.
- Auf eine neue Person oder einen neuen Ort zuerst Original/Quelle, erst danach Rekonstruktion.
