# EP01B V3 — Asset Plan

**Status:** CURRENT — Visual / Source Lock fuer das neue Drehbuch `DREHBUCH.md`  
**Prinzip:** Konzentration > Retention > Beweiswert > Schoenheit.  
**Wichtig:** Die grossen alten Kozyrev-Promptdateien im Ordner stammen aus der frueheren Spiegel-/Remote-Viewing-Fassung und sind **LEGACY**. Fuer die neue Folge gelten ausschliesslich die V3-Dateien.

## Leitidee

EP01B ist keine zweite Spiegel-Folge. Die Bildsprache muss deshalb zuerst **Kozyrev als reale historische Person und Astronom** etablieren. Erst spaet in S7 erscheinen die spaeter sogenannten Kozyrev-Spiegel.

Die Folge arbeitet mit vier Ebenen:

1. **Archiv / Original:** Mond, Pulkovo, Kozyrev-Portraet, Norilsk-Kontext, reale spaetere Spiegel.
2. **Dokument / Quelle:** Patent, bibliografische Karten, native Redraws aus Primaerquellen.
3. **Rekonstruktion / AI:** historische Situationen, fuer die kein belastbares freies Original vorliegt.
4. **Motion / Diagramm:** Irreversibilitaet, Stoerquellen, KRAFT/STOERUNG, historische Trennung Kozyrev -> spaetere Forscher -> Spiegel.

**Archiv beweist. Rekonstruktion laesst erleben. Motion erklaert.**

## Empfohlener Produktionsmix

- ca. 30–35 % Original / Archiv / reale Dokumentanker
- ca. 35–40 % hochwertige historische Rekonstruktion
- ca. 20–25 % Motion / Diagramm / Typografie
- ca. 5–10 % Mystery-Holds / atmosphaerische Bridges

Kein fixes Shot-Ziel. Wechsel nur, wenn der neue Shot eine neue Funktion erfuellt.
