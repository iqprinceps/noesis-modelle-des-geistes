# EP09 — Zirbeldrüse I: Das Auge im Inneren

**Status:** Preproduction V1 / drehbuchtechnisch vorbereitet

## Logline

Manche Wirbeltiere besitzen tatsächlich ein lichtempfindliches Parietalauge. Menschen besitzen dieses Auge nicht. Unsere Zirbeldrüse gehört jedoch zu einem sehr alten Pinealkomplex, dessen Geschichte Licht, biologische Zeit und Verhalten verbindet. Die Folge verfolgt, was aus diesem alten Lichtsinn bei Säugetieren geworden ist.

## Zuschauerpromise

Am Ende versteht der Zuschauer:

1. was das echte Parietalauge mancher Tiere ist;
2. wie es mit Pinealorgan und Retina evolutionär zusammenhängt;
3. warum die menschliche Pinealis kein verborgenes Auge ist;
4. wie Licht über Retina, circadianes System und Nervenbahnen trotzdem die Pinealis erreicht;
5. warum gerade diese reale Biologie die spätere Mystik so anschlussfähig machte.

## Leitfrage

**Was bleibt von einem Auge übrig, wenn es nicht mehr selbst sehen muss?**
