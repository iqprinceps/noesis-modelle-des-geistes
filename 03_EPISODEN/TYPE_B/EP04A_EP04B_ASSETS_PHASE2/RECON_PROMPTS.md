# EP04A / EP04B — KI Reconstruction Prompts

## Global Reconstruction Lock

Jede generierte historische/biografische Szene wird im Edit als **REKONSTRUKTION** behandelt. Generierte Bilder sind niemals Beweis für ein historisches Ereignis.

Für alle Prompts:
- 16:9, cinematic investigative documentary, restrained realism.
- Period details plausibel, keine sichtbaren modernen Gegenstände in historischen Szenen.
- Keine Fake-Dokumente, keine Fake-Zitate, keine erfundenen lesbaren Sanskrit-/Deutsch-/Englisch-Passagen.
- Keine KI-Portraits realer historischer Personen als angebliches Archivbild.
- Bei realen Personen: entweder lizenziertes Portrait separat im Edit oder generischer Darsteller / Rückenansicht / Hände.
- Keine generischen „mystic India“-Klischees, keine leuchtenden Augen, kein Fantasy-Nebel als Abkürzung.
- Die schwarze Schlange aus Jungs Innenwelt **nie** visuell als „Kundalini = dieselbe Schlange“ behaupten.
- Moderne siebenfarbige Chakra-Grafik **nie** als Illustration von 1577 oder einer unveränderten alten indischen Standardkarte.
- Red-Book-Ästhetik nur abstrakt; keine kopierten Seiten, Figuren, Mandalas, Texte oder Kompositionen.

# Production labels

Recommended edit label for subjective/historical generated scenes:

`REKONSTRUKTION`

For motion built from real historical assets, no reconstruction label is needed if the source objects remain identifiable; when a synthetic 1919 title card or invented spatial scene appears, label it.
