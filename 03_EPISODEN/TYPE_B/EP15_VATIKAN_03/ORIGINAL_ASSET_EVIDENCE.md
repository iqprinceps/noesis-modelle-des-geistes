## Goal
The episode should be carried by real documents and material objects, not generic “secret Vatican” B-roll. Each visible text passage is tied to a scan/edition; later artworks are clearly separated from historical evidence.

## O01 — Early Donation manuscript — St. Gallen Cod. Sang. 670, p.318
- Direct file page: https://commons.wikimedia.org/wiki/File:The_Donation_of_Constantine,_page_318.jpg
- What it is: 9th-century manuscript page in the Pseudo-Isidorian / False Decretals transmission; red rubric identifies Constantine’s letter to Pope Sylvester.
- Use: **Shot 1 / opening hero**. It gives the audience a real medieval witness immediately.
- Rights: Commons PD/PDM classification; retain St. Gallen provenance and perform final institution/territory check.

# Acceptance criteria

1. Every visible text passage matches the selected scan/edition.
2. Folio/page/edition is documented in the production manifest.
3. No highlight changes the meaning of the source.
4. Original document, medieval copy, later artwork and modern scholarly interpretation are visually distinguished.
5. BAV/Vatican Museums web images are not treated as freely reusable merely because the underlying artwork is old.
6. CC BY/CC BY-SA attribution/license obligations are stored with the asset.
7. The Donation manuscript is never described as a surviving 4th-century original.
8. The Gratian line uses “later Gratian tradition / Paleae” unless a more exact manuscript-specific claim has been separately proven.
9. The print-history line uses 1506 as the current bibliographic first-print lock; Hutten is not labeled first edition.
