# EP15 — Vatikan III: Das Dokument, das dem Papst den Westen gab

## Kern
Die Konstantinische Schenkung als Dokumenten-Mystery: Ein Text behauptet eine imperiale Übertragung von Macht an Papst Silvester; Jahrhunderte später untersucht Lorenzo Valla die Behauptung mit Sprach- und Geschichtsanalyse.

## Dramaturgischer Motor
Nicht „Kirche beim Lügen erwischt“, sondern die stärkere Frage: **Wie kann ein historisch falsches Dokument reale Macht entfalten?**

## Hook-Asset
Bevorzugt echte frühe Donation-Handschrift bzw. hochauflösende historische Darstellung der Donation-of-Constantine-Tradition. Kein generisches Vatikan-Establishing.

## Bildstrategie
Die Folge kann jetzt drei klar getrennte Ebenen zeigen:
1. **Legende** — mittelalterlicher Sylvester-Zyklus und spätere Donation-Ikonografie.
2. **Materielle Geschichte** — echte Constantinianische Münzen, Porträtskulptur, historische Rom-/Lateranobjekte.
3. **Textforensik** — Donation-Manuskripte, Valla-Handschriften, Marginalien, Frühdrucke und kanonistische Überlieferung.

Damit entsteht Mystik aus dem echten historischen Material selbst; generische esoterische Stockbilder oder erfundene „Vatikan-Symbole“ sind nicht notwendig.
