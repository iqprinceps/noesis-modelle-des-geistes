# EP15 — Script QA

## Ergebnis
**PASS — Preproduction / Source & Asset Lock**

## Hook
**Sehr stark.** Der Zuschauer bekommt sofort eine ungeheure, konkrete Behauptung: ein Kaiser verschenkt den Westen. Der Satz „Stellt euch vor, dieses Dokument wäre echt“ erzeugt sofort eine offene Schleife.

## Retention
- 0–30 s: maximaler Claim + überraschender Echtheitsbruch.
- frühe Phase: Warum Konstantin als Name überhaupt Macht trägt.
- Midpoint: Valla wird zum historischen Ermittler.
- zweiter Payoff: Eine Fälschung kann trotzdem reale Geschichte erzeugen.
- Ende: organischer Medienwechsel zum Index.

## Mystik/Atmosphäre
Gut. Keine reflexive Widerlegung. Das Rätsel wird nicht dadurch klein, dass der Text falsch datiert ist; seine Wirkung wird dadurch paradoxer.

## Faktische Risiken vor Voice-Lock
1. Konkrete Datierung der Donation nur mit wissenschaftlich vorsichtiger Formulierung.
2. Exakte Rolle im Decretum Gratiani/kanonistischen Corpus vor eingeblendeter Manuskriptseite prüfen.
3. Valla-Zitate nicht aus Sekundärparaphrase übernehmen.
4. Tauferzählung anhand seriöser spätantiker Quellen/Standardwerke absichern.
5. Erstausgabe von Vallas Kritik bibliografisch locken.
6. Vatikan-Digitalisat: Reproduktionsrecht separat klären.

## Produktionsurteil
Dramaturgisch produktionsfähig. Für Voice-Lock fehlen nur die endgültigen Primärtextstellen und Rechtebelege der Hero-Assets.
