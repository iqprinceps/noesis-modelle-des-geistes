# EP14 — Vatikan II: Das Archiv unter Rom

## Serienrolle
Teil 2/5 der Vatikan-Miniserie. Nach EP13s persönlichem Prophezeiungs-/Objekt-Mystery wechselt die Serie zum institutionellen Gedächtnis und zur Macht historischer Dokumente.

## Kernversprechen
Wir betreten das Vatikanische Apostolische Archiv nicht über eine generische Vatikan-Tour, sondern über ein reales, spektakuläres Objekt: den 1530er Brief englischer Lords an Clemens VII. mit 81 Siegeln. Von dort öffnet sich die Geschichte zu Zugang, Untergrundbunker, Galileo, Napoleon, Templerakten und Digitalisierung.

## Hook
**Erster Shot:** Makro/Tracking über die 81 erhaltenen Siegel der Causa Anglica. Kein Logo, keine Drohne, keine Petersdom-Totale davor.

**Voice:** „Ein Brief. Ein Papst. Ein König, der eine andere Frau heiraten will. Und einundachtzig Siegel, die ihn unter Druck setzen sollen.“

## Leitfrage
**Was bewahrt der Vatikan dort unten auf — und warum erzeugt ein historisches Forschungsarchiv bis heute die Vorstellung eines verbotenen Wissensspeichers?**

## Retention-Motor
81 Siegel → alter Name Secretum → Zugang → realer Untergrundbunker → Galileo → Napoleon verschleppt das Archiv → Verluste/Vernichtung → Templerprozess → sieben Millionen Digitalbilder → Rückkehr zum 1530er Dokument → Übergang zur Konstantinischen Schenkung.

## Ton
Mystery und institutionelle Macht zuerst. Keine Folge nach dem Muster „Vatican conspiracy debunked“. Sprachliche und historische Präzision wird in die Story integriert, ohne die Faszination abzuräumen.
