## Rights workflow for AAV imagery
Official rights page: https://www.archivioapostolicovaticano.va/content/aav/en/consultazione/fotoriproduzioni.html

Before use, request:
- purpose: professional/editorial audiovisual publication;
- exact shelfmark;
- exact image/page/folio;
- territory/platform/term if requested;
- reproduction master or authorised image;
- written permission and fee quote.

Keep the required AAV credit line exactly as granted. Web visibility is **not** commercial reuse permission.

## Acquisition metadata required per final asset
- asset_id
- exact source URL
- institution / creator
- object title
- date
- exact depicted identity/content
- archive shelfmark / folio / page where applicable
- licence / rights statement
- commercial YouTube reuse status
- attribution requirement
- original download URL / IIIF endpoint
- scene/use
- crop restrictions
- verification date
- local production filename / checksum after download

## Prohibited shortcuts
- Pinterest as source.
- Random blog images.
- Google Images result URLs as source records.
- Assuming “old object = free modern scan/photo”.
- Generic parchment while narration claims it is the Causa Anglica.
- Random Templar manuscript during a claim about a specific proceeding.
- Baphomet/Lévi imagery presented as proof of medieval Templar occult practice.
- Modern archive stock footage labelled as the Vatican bunker.
