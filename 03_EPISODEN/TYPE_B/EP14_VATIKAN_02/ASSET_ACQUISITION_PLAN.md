# EP14 — Asset Acquisition Plan

## Grundsatz
Diese Folge muss sichtbar dokumentarisch sein. Generierte Bilder dienen nur für nicht erhaltene Handlungsmomente, Übergänge und räumliche Rekonstruktionen. **Originaldokumente tragen die Glaubwürdigkeit und die Retention.**

## P0 — Muss vor Production Lock beschafft/geprüft werden

### A01 — Causa Anglica / 81 Siegel
Source target: Vatican Apostolic Archive, `Exemplaria Praetiosa`.
Need: Gesamtansicht + hochauflösende Details der Siegel + Unterschriften/Schrift.
Use: allererster Shot, S1, Rückkehr S9, Thumbnail-Kandidat.
Rights: institutionelle Reproduktionsrechte separat klären; Websichtbarkeit ist keine kommerzielle Freigabe.
Fallback: lizenzierte Presse-/Ausstellungsfotografie; keine KI-Nachbildung als „Original“.

### A02 — Vatikanisches Archiv / historische Räume
Need: authentische Außen-/Innenaufnahmen, Eingang, Lesesaal, historische Regale.
Use: S2–S3.
Rights: offizielle Presse-/Archivfreigaben prüfen.

### A03 — Bunker unter Cortile della Pigna
Source target: offizielle AAV-Seite / autorisierte Fotografie.
Need: reale Magazinansichten; wenn Innenbilder nicht lizenzierbar, Außen-/Grundriss + klar markierte filmische Rekonstruktion.
Use: großer räumlicher Reveal S4.

### A04 — Galileo
Need: PD/CC Porträt von Galileo; originale/autorisiert reproduzierbare Prozessseiten; Signatur und exakte Seite locken.
Use: S5.
Preferred image repositories: Wikimedia Commons mit Einzeldatei-Rechteprüfung; Gallica/Europeana/Wellcome nur bei passendem Objekt.

### A05 — Napoleon / Archivtransport 1810
Need: PD Napoleon-Porträt, zeitgenössische Rom-/Paris-/Transportdarstellungen, Karten.
Use: S6.
Generated: nur Transport-Reconstruction; keine generierte Fälschung historischer Archivbilder.

### A06 — Templerprozess
Need: echte Prozessurkunde/Faksimile aus `Processus contra Templarios`, ggf. Chinon-Pergament falls inhaltlich exakt passend; mittelalterliche Templerdarstellungen mit geklärter Reproduktionslage.
Use: S7.
Warning: Templerbilder niemals als Beleg für Schatz-/Okkultbehauptungen montieren.

### A07 — Digitalisierung
Need: Scanner/Conservation/Digital Lab des AAV oder neutraler authentischer Archiv-Digitalisierungsprozess.
Use: S8.

## Acquisition metadata required per final asset
- asset_id
- exact source URL
- institution/creator
- object title
- date
- exact depicted identity/content
- license/rights statement
- commercial YouTube reuse status
- attribution requirement
- download/original URL or IIIF endpoint
- scene/use
- crop restrictions
- verification date

## Prohibited shortcuts
- Pinterest as source.
- random blog images.
- Google Images URL as source record.
- assuming medieval/old object = scan/photo is public domain.
- using generic parchment while voice claims it is the Causa Anglica.
- showing random Templar manuscript during a claim about a specific proceeding.
