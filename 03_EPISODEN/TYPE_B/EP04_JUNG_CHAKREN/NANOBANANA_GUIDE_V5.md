# EP04A — NanoBanana / Image Generation Guide V5 FINAL

**Production principle:** generated imagery exists only where it is the best tool for the story. Archive and real historical objects take priority whenever they can carry the beat.

## Coverage profile

EP04A needs a larger generated pool than EP04B because its strongest material is subjective and cannot be represented honestly by archival stand-ins.

Current planned pool:
- **44 MAIN generated frames**
- **8 RESERVE frames**
- plus real archive, historical diagrams, documents, locations, motion graphics and editorial crops

These numbers are not a target to fill. If a real archive shot or one strong generated frame carries two adjacent beats better, use it. If a generation is weak, skip it or use a reserve. The edit follows the final voice, not a fixed shot count.

No global prompt has to be manually prepended.

## Hard visual locks

- Jung's 1913 black snake is a subjective reconstruction. Never make it look like the historical Kundalini snake from a source plate.
- Do not copy Red Book pages, figures, mandalas, lettering or compositions.
- No fake archive documents or fake quotation cards.
- If Jung is recognizably present in a generated historical scene, use an authentic portrait reference and label the scene `REKONSTRUKTION` on first appearance.
- No generic occult props, tarot, glowing chakras on bodies, cosmic energy beams or psychedelic wellness imagery.
- Historical 1932 Kundalini diagrams are shown as real source objects, not regenerated.
- Modern body/phone scenes are contemporary documentary reconstructions, not stock-like lifestyle advertising.
- Visible text is avoided inside generated frames; German typography is built in edit.
- Practical light only in interiors. No cyan/magenta aurora spill on skin, paper or furniture.
- 16:9, premium documentary realism or controlled conceptual surrealism depending on the named style reference.
