## Corrections / editorial locks

1. **Galileo:** distinguish the 1616 Copernican decree from the later prohibition of the *Dialogo*. The later historical Index line checked in this pass prints `Decr. 23 Augusti 1634`; do not visually label that particular line “1633.”
2. **Descartes:** `donec corrigantur` is now corroborated. A later Index scan gives the exact abbreviated form `Donec corrig.` for *Meditationes* with a 10 Oct 1663 decree. Keep narration at the level of “major writings / several works in 1663,” not “every Descartes work was banned on one date.”
3. **1948:** the **xxiv + 508 page** extent is verified through multiple library records. A rights-clean scan is **not** locked; acquire title page + representative leaves from a holding library rather than using Google Books as picture source.
4. **1559/1564:** the 1564 book itself is now available as a rights-clean PD scan. The 1559 facsimile is useful for structural research, but production should seek the BSB digital original before picture-lock if a 1559 page is required.
5. **Vatican 1966:** claims are primary-source safe; screenshot/reproduction rights are not automatically open just because the page is public.

## Production principle
Never write a fake “Index” page. For each evidence shot, show the **real edition + real printed page/scan locator + exact narration claim**. Use `ASSET_MANIFEST_VERIFIED.md` as the acquisition/rights sheet.
