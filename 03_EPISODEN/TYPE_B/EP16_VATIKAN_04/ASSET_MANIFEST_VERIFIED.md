## 10. Rights / credit sheet

- **Public Domain / PDM assets:** retain source URL + institution in project metadata even when attribution is not legally required.
- **CC0:** PAP-01 and PAP-02 can be commercially reused; still credit the holding institution as editorial best practice.
- **CC BY-SA 2.0:** PAP-03 requires attribution, licence link and ShareAlike compliance for adaptations.
- **Vatican web documents:** text is an official primary source, but the website does not state an open-media licence on the pages checked. Use short quotation/source citation or seek screenshot/reproduction clearance.
- **1948 Index:** bibliographic facts are verified; **image rights are not yet locked**. Treat this as the only Tier-A acquisition gap.
- **Research mirrors:** never become the final visual merely because they expose searchable OCR.
