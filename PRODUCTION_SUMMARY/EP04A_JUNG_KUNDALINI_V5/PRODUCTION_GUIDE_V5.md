## What makes this episode different

EP04A moves repeatedly between verifiable history and subjective inner imagery. Its production therefore uses a larger reconstruction pool, more atmosphere changes and more voice performance splits than EP04B. Numbers in the old script timing table are editorial orientation only; they are not delivery targets.

## Production sequence

1. Run archive downloader / rights pass.
2. Pull real historical source objects first.
3. Generate only the missing/reconstruction coverage needed by the cut.
4. Audition voice names, then run full 12-stem batch.
5. Build VO master + forced alignment.
6. Generate project-owned music/SFX stems from real VO timing.
7. Build motion graphics from authentic sources.
8. Cut to text anchors in `VISUAL_CUE_SHEET_V5_FINAL.csv`.
9. Generate captions from alignment.
10. Thumbnail, endscreen hold, source credits and final technical QA.

## Non-blocking source fallbacks

- Exact direct-quote page for Jung's warning is **not required** to begin production. Default motion card is a clearly labeled paraphrase; a direct quote is used only if separately locked.
- No exact 1932 seminar photograph is required. Seminar room is reconstruction and is labeled as such.
- No Red Book image is required or assumed cleared.
- The verified Serpent Power full scan is 1924; `1919` is bibliographic context, not a fake facsimile.

## Final QA

Judge the episode by whether each visual/sonic change earns attention and preserves source discipline. Do not add images, cuts or stems merely to reach a count.
