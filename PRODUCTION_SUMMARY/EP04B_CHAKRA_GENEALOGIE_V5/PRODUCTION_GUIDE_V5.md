# EP04B Chakra-Genealogie — Production Guide V5

**Status:** READY FOR PRODUCTION INPUTS  
**Core rule:** let real historical objects carry the detective story.

## What makes this episode different

EP04B already has rich historical material. It should not inherit EP04A's reconstruction density. The edit is built around source objects, detail crops, transparent layers and morph/route graphics; generation exists only for gap filling and modern/contextual reconstructions. Old script timing estimates are orientation only, never runtime locks.

## Production sequence

1. Download GREEN archive and save credits/license sidecars.
2. Build source-object board before generating anything.
3. Generate only contextual/gap-fill frames from the two prompt batches.
4. Run pronunciation preview and full 10-stem voice batch.
5. Build master + forced alignment.
6. Generate project-owned EP04B audio stems.
7. Build source-led motion graphics.
8. Cut by text anchor and source readability, not a uniform shot duration.
9. Captions, credits, thumbnail and final QA.

## Non-blocking source fallbacks

- NPG Woodroffe portrait remains reference-only: production uses High Court/book context plus generic reconstruction.
- No verified Atal Bihari Ghose portrait is needed: name/network motion + scholarly-hands reconstruction carries the beat.
- 1919 first-edition visual is a clean bibliographic graphic; real public-domain scan shown is labeled as 1924.

## Final QA

If the cut feels too synthetic, remove generated material before adding more. EP04B should look like a real archive being opened, not an AI documentary about an archive.
