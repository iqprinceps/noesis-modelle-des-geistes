# EP02 Gateway — Discovery and Packaging Profile

Checked: 2026-08-27

## Viewer intent

The likely cold viewer searches for an explanation of the Gateway Process,
Gateway Experience, Hemi-Sync or the popularly named CIA Gateway Report. The
episode's most distinctive promise is not a generic summary of the tapes; it is
the original Army report's proposed test using observers in three different
times.

## Current search language

Primary phrase: `CIA Gateway Process explained`

Relevant supporting phrases found in current YouTube suggestions:

- `Gateway Process explained`
- `Gateway Process Hemi-Sync`
- `Gateway Process report`
- `CIA documents Gateway Process`
- `Gateway Experience`

Searches for uninterrupted tapes, sleep audio or a guided Wave 1 session are
intentionally not targeted because this documentary does not provide those
experiences.

Keep this package while it accurately attracts the intended viewer. Reconsider
only when actual search terms, impression context, click behaviour and retention
