# EP02_EN Viewer Label Policy Override

Status: binding episode override

This file also records the binding quantity/sequence override from the
repo-wide constraint audit. `01_GLOBAL/00A_PRODUKTIONS_INDIVIDUALITAET.md` and
the current user decision supersede older quota-like wording.

## Visible picture

- No permanent `ARCHIVE`, `ORIGINAL DOCUMENT`, `RECONSTRUCTION`, `MODEL`, or
  `INNER / HYPOTHESIS` badge.
- Portraits: no archive badge.
- Original documents: one concise source/date line at the first relevant proof,
  or a targeted highlight of the authentic line.
- Reconstructions: visually distinct treatment. A discreet 1.5–2.0 second
  contextual line is optional only at the first entry into one continuous block.
- Abstract/mystical passages: no category label.

## Internal records

Every asset and cue still records its evidentiary mode, source lineage, rights
status, and whether a reconstruction-block context line is required. QA rejects
any accidentally persistent mode badge.

## QA gate

The final contact-sheet and clip checks must explicitly confirm:

1. no permanent mode badges;
2. no visible `INNER / HYPOTHESIS` label;
3. no archive badge on portraits;
4. document source/date context appears only where evidentially useful;
5. reconstruction context, if used, lasts 1.5–2.0 seconds at block entry only.

## No creative quotas

- The ten named motion ideas are candidates, not a delivery quota.
- Shot, still, archive, card-state, reserve, and reconstruction quantities are
  candidates until the selected full voice is aligned.
- Concepts may be merged or removed when the cue sheet shows that archive,
  document motion, crop movement, or an existing state covers the beat better.
- Generate only when the asset improves viewer comprehension, retention,
  mystery, voice-picture fit, or quality enough to justify its cost.

## Binding production order

1. source and rights audit plus canonical script/hook-timing audit;
2. two short voice auditions using the identical excerpt;
3. select voice/settings and generate one full master;
4. forced alignment;
5. cue sheet;
6. only the assets demonstrated necessary by that cue sheet.

## Linear picture lock

- A selected still, document crop, map, card, or clip may occupy one contiguous
  timeline block only. Once the cut leaves it, that export cannot return.
- Zoom, crop, pan, color, and overlay variants of the same export do not create a
  new asset. A callback requires a different source, action, composition, or a
  genuinely advanced diagram state.
- Video source ranges progress once and are never restarted.
- The same rule applies across English episodes. Every selected asset is recorded
  as `series_usage=EP02_ONLY` and checked against the shared series registry.
- Static holds normally run 3–6 seconds. Every hold at or above 8 seconds gets a
  viewer-retention review; an over-10-second hold requires visible internal
  development, not camera drift alone.
- Release gate: asset returns 0, exact and near repeats 0, cross-episode
  collisions 0, visible mode badges 0.
