# EP05_EN Preproduction Visual Decisions

These decisions protect the intended viewer experience. Asset quantities remain
adjustable after voice alignment.

## Locked story-image relationships

- When Hufford is named, use a rights-safe authentic identity/book/biographical
  anchor or a clearly non-identifying action shot. Never present a generated man
  as David Hufford.
- When Fogo Island or the Old Hag tradition is discussed, show the actual place,
  map, archival/contextual material or a faithful material-world reconstruction.
- When REM atonia is discussed, pair real PSG/EEG evidence with one simple
  embodied model.
- When Cheyne is named, use the actual publication/profile source if rights allow
  or an anonymous research context. Never invent his likeness.
- When Takeuchi 1992 is named, reveal the real paper/title/abstract context before
  the laboratory reconstruction. Show the relevant full line and result cleanly.
- When `six episodes` is spoken, six must land visibly as the result rather than
  disappear inside a paragraph.
- When Bridget Bishop is named, use a real Salem source or licensed historical
  archive anchor with a legible relevant excerpt.

## No-return sequence rule

The final cue sheet has one forward visual path. Once an underlying image,
document, card or clip state leaves the timeline, it does not return. Callbacks
receive new compositions or visibly later states; reframing the same file does
not qualify.

## Viewer-facing labels

Internal manifests classify evidence and imagery. These classifications are not
persistent on-screen furniture. The episode uses coherent visual grammar and
context to distinguish original sources, explanation, reconstruction and inner
experience.
