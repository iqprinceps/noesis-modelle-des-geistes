# English Discovery, Metadata and Packaging

This is a flexible decision guide, not a lock file. Its purpose is to help each
episode earn a useful first YouTube test through clear audience promise, honest
search language and strong title/thumbnail packaging.

There are no mandatory title formulas, keyword counts, tag counts, character
targets, thumbnail word counts or fixed publication hours. A choice is retained
only while it is the best fit for the specific episode, its intended viewer and
the current channel data.

## Episode-first discovery review

Before an upload, review the individual episode from the viewer's side:

1. Identify the real search language currently used for this subject. Check
   YouTube suggestions, visible competing results and the channel's own search
   traffic where enough data exists.
2. Define the viewer's likely intent: explanation, documentary, original
   document, experiment, experience, biography, mystery or practical method.
3. Select one primary discovery phrase and a small set of genuinely relevant
   supporting phrases. Do not add adjacent popular terms that the episode does
   not satisfy.
4. Put the recognisable subject early enough in the title and description for a
   cold viewer to understand it immediately. Natural language and curiosity are
   more important than repeating a phrase mechanically.
5. Make title and thumbnail complementary. The title should establish subject
   and promise; the image should create the unresolved visual question. They
   should not spend the same words saying the same thing.
6. Use the first description lines to confirm the promise in searchable plain
   English. Continue with a concise story setup, chapters, useful source links
   and one episode-specific interaction question.
7. Use tags for exact subject variants, meaningful entities and common search
   formulations. Tags are supporting metadata, not a reason to keyword-stuff.
8. Supply accurate English captions, correct language fields, a custom
   thumbnail and the relevant series playlist. These help comprehension and
   channel navigation even when they do not independently create impressions.

## Accuracy and intrigue

Popular search wording may be quoted when the episode directly investigates
that wording. If the popular label is misleading, the title or opening
description should preserve the search bridge while the episode immediately
clarifies the distinction. Search optimisation must never introduce a promise
the video cannot satisfy.

Mystery is welcome. A title can pose a question, reveal a contradiction or open
an unresolved theory. It does not need to read like a lesson. The packaging
should sell the strongest honest experience contained in that episode.

## After publication

Treat the initial package as a testable hypothesis. Review it when meaningful
data has accumulated, without reacting to tiny samples. Consider together:

- impressions and their traffic sources;
- search terms that actually brought viewers;
- click-through behaviour in context;
- first-minute retention and average view duration;
- comments, subscribers gained and continuation into the series;
- whether the audience received the promise made by title and thumbnail.

If a change is justified, prefer a focused title or thumbnail refinement whose
effect can be interpreted. Do not repeatedly rewrite metadata merely because a
new channel has few impressions. Long-term priority remains viewer satisfaction:
the package earns the click, and the episode must keep the promise.

## Per-episode record

Every English upload folder should contain an episode-specific `SEO_PROFILE.md`
recording the current search language, viewer intent, selected title,
title/thumbnail relationship, description opening, interaction prompt and any
later data-led revision. These profiles are living decisions, not inherited
templates for the next episode.
