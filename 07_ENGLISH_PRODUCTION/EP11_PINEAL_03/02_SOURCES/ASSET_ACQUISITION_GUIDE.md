# EP11_EN — Expanded Original Asset Acquisition Guide

This is the production-facing acquisition guide for the English Pineal Episode 3. It expands the core manifest into a broad, redundant asset pool so the edit is not forced to recycle a handful of images.

## Acquisition objective

Build a rights-aware pool large enough to support an 8–9 minute documentary episode with distinct visual states:

1. people / identity;
2. primary documents;
3. nineteenth-century zoology and comparative anatomy;
4. real human pineal anatomy;
5. Ajna / subtle-body history;
6. Theosophical synthesis;
7. Shiva / third-eye iconography;
8. later occult gland mapping;
9. DMT laboratory bridge.

The file `ASSET_POOL_EXPANDED.csv` is the machine-readable source of truth for individual candidates.

## B. Blavatsky primary-document evidence

### *The Secret Doctrine*, Vol. II (1888)
The viewer-facing proof should come from a complete public-domain scan, not a modern transcription screenshot.

**Required page states:**

- p. 289 — section title / beginning of “The Races with the Third Eye”;
- pp. 294–301 — sequence where eye-like organs, pineal gland, Eye of Shiva and Blavatsky's human-evolution narrative converge.

Reference transcription:
- https://www.theosociety.org/pasadena/sd/sd-hp.htm
- https://sacred-texts.com/the/sd/sd2-0-co.htm

Codex should locate the cleanest complete 1888 scan available from an institutional/public-domain repository, preserve the cover/title-page context, and record the scan source separately from the underlying text copyright status.

**Picture-lock states:**
1. full page without highlight;
2. gentle guided crop;
3. exact line highlight;
4. adjacent page spread if visual continuity helps.

Never show isolated words floating on black as if they were the original document.

## Final acquisition rule

Every actual binary must be written to external production storage and have:

- canonical source page;
- direct download URL;
- creator/institution;
- original date;
- exact rights/license statement;
- license URL or source-page rights field;
- retrieval date;
- SHA-256;
- dimensions/pages;
- external path;
- narration beat;
- claim limit;
- status: acquired / rejected / rights hold / substitute.

Do not mark an asset `ACQUIRED` until the binary itself has been downloaded and inspected.
