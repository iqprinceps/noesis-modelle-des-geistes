# EP11_EN — Image Generation Prompt Lock

All generated images are reconstructions or symbolic visualizations. They must never replace primary documents where the narration is making a historical claim.

Default delivery: 16:9, cinematic documentary realism, high detail, restrained color, no text, no labels, no logos, no fake archival damage, no embedded captions.

## Negative continuity rules

- Never generate a fake Blavatsky or Leadbeater portrait.
- Never generate a fake page from *The Secret Doctrine*, *The Serpent Power* or *The Chakras*.
- Never show Ajna as literally located in the pineal gland during the historical-source section.
- Never show the nineteenth-century reptile evidence as evidence for a lost human organ.
- Never present DMT imagery as proof of mystical experience, dreams, birth or death.
- Original documents should enter the edit before any reconstruction that interprets them.
